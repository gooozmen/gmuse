# Security Policy

## Reporting a vulnerability

If you think you have found a security vulnerability in gmuse, please do not open a public issue.
Use the repository's private vulnerability reporting instead: **Security → Report a vulnerability**.

Vulnerabilities in the shared score engine, the file readers or the desktop application also exist
in upstream [TuxGuitar](https://github.com/helge17/tuxguitar/security). If the problem is not specific
to gmuse's Android interface, please report it there as well.
